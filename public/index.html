Public Reading Room

The Riverbend Civic Archive keeps meeting minutes, renovation notes, local photographs, and small civic objects donated by residents. This mirror is maintained for visitors using home computers and the library terminal.

This is an archive investigation, not a normal puzzle menu. Treat the site like a real old mirror: follow stale notes, inspect page source, try hinted addresses, watch URL parameters, and notice what the server says outside the page itself.

The volunteer webmaster is no longer accepting new submissions by email. Existing public pages remain online while the archive is reorganized.
